# raposza-target-2x

Translation implementation for Canton 2.9 and 2.10, over Ledger API v1.

This is the complete client implementation: participant identity, parties,
users, the active contract set, single contracts, transaction trees and command
submission. Measured against a 2.9.6 participant.

SDK types permitted.
Comprehensive 2.x coverage is a separate delivery concern.
